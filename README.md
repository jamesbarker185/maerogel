# Maerogel, Universiti Teknologi Malaysia

An interactive isometric figure of how Maerogel turns rice husk, a farm waste, into silica aerogel. Invented by Prof. Halimaton Hamdan.

- `maerogel.html`: the figure (light theme). Move across it to run the process line; press H to light the flame under the tile.
- `maerogel-dark.html`: the same figure in the dark theme.
- `maerogel-preview.png`: a 1200 × 1200 preview image.

The dissolve, gel and dry steps follow the typical sol-gel aerogel route and are generic; the patent's own conditions are not shown. Porosity and density are illustrative.

Built with the Anatomy kit. To rebuild, place this folder at `productions/maerogel` inside the kit and run `node build.mjs` (add `--dark` for the dark page).
